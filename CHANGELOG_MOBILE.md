# Changelog - POS Móvil (Android)

Todos los cambios notables en la aplicación móvil de Android serán documentados en este archivo.

## [1.1.0] - 2026-08-24

### Agregado
- Nuevo sistema de actualizaciones in-app (OTA). La aplicación ahora te avisará automáticamente cuando haya una nueva versión disponible y podrás instalarla directamente.
- Configuración de firma para Release lista para producción.

### Optimizado
- Configuración de red mejorada para descargar actualizaciones directamente de Cloudflare R2 sin intervención del servidor.
## [1.6.0] - 2026-08-26
### Added
- 🚀 Nuevo Sistema de Canales de Actualización (Estable / Beta) integrado en la App Móvil.
- 📱 Soporte oficial para despliegues móviles integrados con el servidor.

### Changed
- 🎵 Mejorada la experiencia de usuario: el sonido del escáner en auditorías y control de stock ahora suena natural y reacciona sin latencia.
- ⚡ Optimización de Rendimiento: Limitador de peticiones silenciosas que reduce el consumo de red y CPU del servidor en un 80% al navegar.

### Fixed
- 🔒 Seguridad Reforzada: Corrección en el Muro de Fuego que provocaba bloqueos erróneos de permisos de Acceso Remoto.
- 📱 Interfaz Móvil: Solucionado un error visual ('overflow') que deformaba la pantalla de bloqueo al abrir el teclado en celulares.
